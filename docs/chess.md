## How updates work

- Move links contain the game and position revision. Old links and illegal moves are rejected.
- Only the owner can play Black or start a new game after the current one ends.
- Checkmate and automatic draw conditions show "Good game! Thank you." until John starts the next game.
- Moves are processed one at a time. A second request for an old position cannot replace the accepted move.
- A GitHub @mention generates a notification according to John's GitHub notification settings. Email and phone push depend on those settings.

Rules are checked with chess.js 1.4.0 (BSD-2-Clause). Piece illustrations are original SVG shapes.
