# Dioxyzine Frog

[Back to my profile](../../README.md)

## Introduction

I'm building an e-commerce website for custom plushies, dolls and accessories. The project connects a customer-facing storefront with accounts, order tracking and administration workflows.

## Problem

Keep product discovery, checkout and order follow-up connected in one website, while making the administration tools usable for the shop.

## My role

Frontend development and service integration, including backend parts of checkout and order management.

## Main features

- Product listings, product details and a shopping cart
- Account registration, sign-in, password reset and profile pages
- Checkout with PayPal Sandbox
- Order tracking and product/order administration

## Stack

React, Vite, JavaScript, Supabase, PayPal Sandbox

## Demo or walkthrough

[Open the demo](https://dioxyzinefrog.vercel.app)

## Learning focus

These notes describe the concepts I am practising in the implementation.

- Tracing checkout through the UI, payment capture and stored order state.
- Connecting account and admin flows to database access rules.

## Status and outcome

**Implemented source with Sandbox payments**

A documented web application spanning storefront, accounts, checkout and order workflows.

## Limits

- Repository documentation does not certify every production integration as fully verified.
